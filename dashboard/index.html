How the value is worked out

implied = TVL × category multiple × growth × maturity × breadth

  • Category multiple — the median market-cap / TVL of the live protocols in the same category, priced from this same snapshot. A lending protocol is priced like live lending protocols, a DEX like live DEXs. Categories with fewer than 3 live comparables take the whole live set's median.
  • Growth — 1 + clamp(7d change, −40%, +60%) × 0.6. A +4,448% week is a data spike, not a trend, so the growth leg is capped hard.
  • Maturity — 0.70 + min(age, 1095 days) / 1095 × 0.30. Older with no token means more pent-up launch value; a young protocol earns its place on growth and size. Age is listed_at to the snapshot date; unknown age counts as 365 days.
  • Breadth — 1 + 0.02 × extra chains (at most 5 extra): a protocol live on more chains reaches more farmers.
